Green is not the same as safe

Some breaks pass the build. Bootshift tells you anyway.

While testing the recipes on our own fixtures, Jackson 3 started rejecting request bodies that leave out a primitive field. The tempting fix edits the test. The right one keeps the API contract and flags the change for a human.

Review by hand
  • FAIL_ON_NULL_FOR_PRIMITIVES is on by default in Jackson 3: missing boolean fields now return 400.
  • Default date output changes from timestamps to ISO strings.
  • PathPatternRequestMatcher rejects ** in the middle of a pattern.

Found in Phase 0 on the simple-web and security-chain fixtures.

Stop patching Boot 3. Start verifying Boot 4.
